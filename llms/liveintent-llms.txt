# LiveIntent

> LiveIntent is a people-based email marketing, advertising and identity platform serving more than 2,500 businesses. It connects marketers and publishers through email-native audience targeting, publisher inventory monetization (LiveTag and native ad blueprints), and identity resolution across the digital ecosystem. LiveIntent has been acquired by Zeta Global. It publishes four APIs — three of them documented, two of them with machine-readable OpenAPI definitions — plus the open-source LiveConnect first-party identity library.

Generated 2026-08-12 by the API Evangelist enrichment pipeline from LiveIntent's own public documentation. Not published by LiveIntent.

## APIs

- [Audiences API](https://audiences.liveintent.com/api-guide): Programmatically create and manage LiveIntent custom audiences — create, search, upload members via signed URLs, read match counts, and create event, URL and conversion trackers. Base URL https://audiences.liveintent.com. Bearer token in the Authorization header. 12 operations, OpenAPI 3.0.0.
- [Privacy Management API](https://privacy.liadm.com/api-guide): Submit GDPR and CCPA data subject requests — opt-out of sale (RESTRICT), delete (ERASURE) and access (ACCESS) — scoped to your account category on the LiveIntent ad exchange. Base URL https://privacy.liadm.com. Bearer token. 8 operations, OpenAPI 3.0.0. Includes a dedicated test-submission endpoint.
- [Reporting API](https://support.liveintent.com/connecting-to-liveintents-reporting-api/): Query publisher and advertiser reporting metrics with splits, filters and absolute or dynamic date intervals. Base URL https://connect.liveintent.com. Username/password login returns a 12-hour bearer token. No OpenAPI published.
- [Programmatic Bidding API](https://support.liveintent.com/programmatic-bidding-api/): LiveIntent's exchange-side OpenRTB integration for DSPs — a subset of IAB OpenRTB 2.5 plus OpenRTB Native 1.1 and 1.2. LiveIntent calls a DSP-supplied bidding URL with tmax=150ms; no-bid is HTTP 204. No OpenAPI published.

## Authentication

- All three callable APIs use an opaque bearer token in the `Authorization` header.
- There is no OAuth 2.0 authorization server, no scopes, no OIDC discovery and no `/.well-known/` document on any LiveIntent host.
- Audiences and Privacy tokens are issued by the LiveIntent account team; there is no token endpoint.
- Reporting tokens come from `POST https://connect.liveintent.com/auth/login/` with a platform username and password, and expire after 12 hours.
- Auth profile: [authentication/liveintent-authentication.yml](https://raw.githubusercontent.com/api-evangelist/liveintent/refs/heads/main/authentication/liveintent-authentication.yml)

## Conventions

- Errors use a proprietary envelope, not RFC 9457: `{"errors":[{"httpStatus","message","errorCode"}]}` — an array. The Reporting API does not use it at all and returns bare `text/plain`.
- Pagination is offset (`page`, `pageSize`) on most Audiences endpoints and cursor (`next`, `pageSize` default 30) on `POST /search/audiences/v2`.
- No idempotency key exists on any operation. Creates and privacy submissions are not retry-safe.
- No rate limits are published, no `429` is declared anywhere, and no rate-limit response headers are documented.
- Asynchronous flows (privacy requests, audience uploads) are polled. There is no partner webhook surface.
- Full detail: [conventions/liveintent-conventions.yml](https://raw.githubusercontent.com/api-evangelist/liveintent/refs/heads/main/conventions/liveintent-conventions.yml)

- [li-privacy](https://pypi.org/project/li-privacy/): LiveIntent's first-party Python CLI for the Privacy Management API. v1.3.2, published 2021-04-13, repository archived. The only first-party client for any LiveIntent API.

## Notes

- No MCP server, A2A agent card, GraphQL endpoint, gRPC service, AsyncAPI document or partner webhook catalog is published. Every `/.well-known/` path returns 404 (or 401 on the authenticated Reporting host).
- No pricing or plans are published. API access follows a negotiated partner relationship; tokens are issued by an account team, not purchased.
- No trust center, security.txt, vulnerability disclosure policy or named security certification could be found. LiveIntent's published compliance posture is privacy-regime conformance — GDPR, CCPA, Global Privacy Control and the IAB Europe TCF Global Vendor List.
- The Zeta Global acquisition is already visible in the contract: `AudienceWithMetadataDTO` carries a `zetaTaxonomyNodeId` field, and some knowledge-base content now serves from knowledgebase.zetaglobal.com/liveintent. Documentation URLs recorded here carry migration risk.
